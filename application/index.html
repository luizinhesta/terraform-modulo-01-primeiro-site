Primeiro laboratório

Neste laboratório você cria um bucket S3, habilita o Static Website Hosting e envia os arquivos index.html e style.css usando apenas Terraform.

O que é Infrastructure as Code?

Infrastructure as Code (IaC) é descrever a infraestrutura em arquivos de texto. Em vez de criar recursos manualmente, você escreve o estado desejado e a ferramenta faz a AWS ficar igual ao que foi descrito.

  • Repetível: o mesmo código gera o mesmo resultado.
  • Versionável: o histórico fica no Git.
  • Revisável: você vê o plano antes de alterar algo.

O ciclo de vida do Terraform

terraform init

Prepara a pasta: baixa o provider da AWS e cria o arquivo de lock.

terraform plan

Compara o código com o que existe e mostra o que será criado, alterado ou removido.

terraform apply

Executa o plano aprovado e cria os recursos na AWS.

terraform destroy

Remove todos os recursos gerenciados, encerrando o laboratório.
